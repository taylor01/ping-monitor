# Deploying ping-monitor on CoreOS with Podman Quadlet

## Prerequisites

- Fedora CoreOS (or any system with Podman 4.4+ and Quadlet support)
- The `hosts.json` configuration file for your site

## Deployment Steps

### 1. Create the config directory and copy hosts.json

```bash
sudo mkdir -p /etc/ping-monitor
sudo cp hosts.json /etc/ping-monitor/hosts.json
```

### 2. Create the secret for SITE_SECRET

```bash
# Create the secret (replace with your actual site secret from the Rails API)
echo "your-site-secret-here" | sudo podman secret create ping-monitor-secret -
```

### 3. Copy the Quadlet container file

```bash
sudo cp ping-monitor.container /etc/containers/systemd/
```

### 4. Edit the container file for your site

```bash
sudo vi /etc/containers/systemd/ping-monitor.container
```

Update these values:
- `SITE_NAME` - your site name (e.g., "home", "cabin", "office")
- `RAILS_API_URL` - your API URL

### 5. Reload systemd and start the service

```bash
sudo systemctl daemon-reload
sudo systemctl start ping-monitor
sudo systemctl enable ping-monitor
```

## Management Commands

```bash
# Check status
sudo systemctl status ping-monitor

# View logs
sudo journalctl -u ping-monitor -f

# Restart
sudo systemctl restart ping-monitor

# Stop
sudo systemctl stop ping-monitor

# Pull latest image and restart
sudo podman pull docker.io/taylor01/ping-monitor:latest
sudo systemctl restart ping-monitor
```

## Auto-Updates (Optional)

The container is configured for auto-updates. To enable:

```bash
# Enable the podman auto-update timer
sudo systemctl enable --now podman-auto-update.timer

# Check timer status
sudo systemctl list-timers podman-auto-update.timer
```

This will automatically pull new images and restart the container when updates are available.

## Updating hosts.json

When you need to update the monitored hosts:

```bash
# Edit the config
sudo vi /etc/ping-monitor/hosts.json

# Restart to pick up changes
sudo systemctl restart ping-monitor
```

## Troubleshooting

### Container won't start

```bash
# Check for Quadlet parsing errors
sudo /usr/libexec/podman/quadlet --dryrun --user

# Check systemd service file generated by Quadlet
sudo cat /run/systemd/generator/ping-monitor.service
```

### Permission issues

The container needs NET_RAW capability for ICMP pings. The Quadlet file includes `AddCapability=NET_RAW`.

### Secret not found

Make sure you created the secret:
```bash
sudo podman secret ls
```

If missing, recreate it:
```bash
echo "your-secret" | sudo podman secret create ping-monitor-secret -
```
